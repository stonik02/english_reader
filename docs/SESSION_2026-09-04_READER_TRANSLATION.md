# Ридер и перевод: изменения 2026-09-04

Этот журнал описывает фактически реализованную механику перевода в ридере и
причины ключевых технических решений. Он нужен при последующих изменениях
перевода, подсветки или EPUB-разметки.

## Поведение для читателя

1. Одно короткое нажатие или клик по английскому слову открывает карточку
   словаря. Слово визуально реагирует на hover и нажатие.
2. Значения и примеры из словаря показываются сразу. Перевод контекста не
   задерживает карточку.
3. Контекст по умолчанию содержит выбранное слово и до трёх слов до и после
   него. Его перевод загружается отдельным фоновым запросом.
4. Полное предложение переводится только по кнопке «Перевести предложение» в
   карточке. Долгое нажатие больше не используется.
5. Если выделить два или более слова, нативное выделение остаётся видимым.
   Появляется кнопка «Перевести выделенное»; только её нажатие открывает
   модальное окно и очищает выделение.
6. Слово из карточки можно добавить в личный словарь как раньше. Сохранённые
   слова подсвечиваются в тексте главы.

## API и backend

`DictionaryService` разделён на два независимых RPC:

| RPC | Назначение | Зависимости |
| --- | --- | --- |
| `LookupWord` | Находит лемму, значения, примеры и статус сохранения. | PostgreSQL, морфология. |
| `TranslateText` | Переводит только явно переданный контекст, предложение или выделенный фрагмент. | PostgreSQL-кэш, глава книги, LibreTranslate. |

Это разделение важно: недоступность или медленный LibreTranslate не должны
блокировать словарную карточку. `TranslateText` проверяет, что текст относится
к текущей главе и отмечает это полем `context_verified`, использует кэш
переводов и возвращает `provider_error` вместо ошибки карточки при проблеме
provider.

Для LibreTranslate установлены безопасные ограничения:

- один HTTP-запрос, без автоматического повтора;
- `TRANSLATE_TIMEOUT=2s`;
- `LOOKUP_SENTENCE_MAX_LENGTH=360` символов;
- circuit breaker остаётся активным после серии ошибок provider.

Переменные заданы в `backend/docker-compose.yml`, `backend/.env.example` и
`deploy/production/docker-compose.yml`. После обычного production-обновления
через `docker compose --env-file .env up --build -d` они применяются к API.

## Frontend и EPUB DOM

HTML глав EPUB приходит как безопасная HTML-строка, а React не знает о
добавленных поверх неё элементах. Поэтому интерактивность реализована так:

- `decorateInteractiveWords.ts` оборачивает слова в `span.reader-word` с
  `data-reader-word`; это не настоящие HTML-кнопки, чтобы не создавать тысячи
  элементов в tab-навигации и не ломать исходную семантику EPUB;
- один обработчик `pointerup` на контейнере главы определяет клик по слову или
  выделение нескольких слов. Не создаётся обработчик на каждом слове;
- кнопка перевода выделенного фрагмента всегда присутствует в DOM, но скрыта
  через `hidden`. Текст выделения хранится в `ref`, поэтому её показ не вызывает
  React-render и не стирает нативное выделение;
- `ChapterArticle` мемоизирован. Открытие модалки, сохранение прогресса и
  другие изменения состояния страницы не перерисовывают большой HTML главы;
- `MutationObserver` следит только за реальной заменой дочернего DOM главы. В
  этом случае интерактивные слова и подсветки восстанавливаются. Полный обход
  главы не запускается при каждом render: это предотвращает фризы на больших
  книгах и задержки hover/модалки.

Не заменяйте мемоизацию главы на `useLayoutEffect` без массива зависимостей:
такой код повторно обходит все text nodes после каждого изменения состояния и
блокирует главный поток браузера.

## Основные файлы

- `protos/reader/v1/dictionary.proto` — контракт `TranslateText`;
- `backend/internal/usecase/dictionary/lookupword/` — быстрый поиск слова;
- `backend/internal/usecase/dictionary/translatetext/` — кэшируемый перевод
  текста;
- `frontend/src/pages/ReaderPage.tsx` — сценарии нажатия, выделения и модалок;
- `frontend/src/features/reader/decorateInteractiveWords.ts` — обёртка слов;
- `frontend/src/features/vocabulary/applyHighlights.ts` — подсветка личного
  словаря;
- `frontend/src/app/global.css` — интерактивное состояние слова и кнопка
  перевода выделения.

## Проверка изменений

Перед публикацией были выполнены:

```bash
cd backend
go test ./...

cd ../frontend
npm run lint
npm run test -- --run
npm run build
```

Также полезна ручная проверка на длинной EPUB-главе: hover не должен иметь
задержки, короткий тап открывает карточку, выделение фразы остаётся видимым до
нажатия кнопки, а сохранённые слова не исчезают после загрузки данных.
