# Озвучивание английского текста

Дата решения: 2026-09-07. Документ относится к
[требованиям v1.3.0](business_requirements/APPLICATION_v1.3.0.md).

## Решение

Для первой версии используем встроенный в браузер **Web Speech API**:
`window.speechSynthesis` и `SpeechSynthesisUtterance`.

Браузер передаёт выбранный английский текст синтезатору, доступному на
устройстве пользователя. Наш frontend не отправляет текст книги в Go API,
PostgreSQL, LibreTranslate или стороннему TTS-провайдеру. Не нужны ключи,
оплата, контейнер или новые порты.

API широко доступен в современных браузерах. `SpeechSynthesisUtterance`
задаёт текст, язык, голос, скорость, высоту и громкость. Голоса получаются
через `speechSynthesis.getVoices()`; в Chrome они могут появиться позже через
событие `voiceschanged`.

Источники: [MDN: Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API),
[MDN: SpeechSynthesisUtterance](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance),
[совместимость браузеров](https://caniuse.com/mdn-api_speechsynthesisutterance).

## Рассмотренные варианты

| Метод | Плюсы | Ограничения | Решение |
|---|---|---|---|
| Web Speech API в браузере | Нет backend, задержки генерации и расходов; запуск по нажатию | Голоса и качество различаются между ОС и браузерами | Выбран для v1.3 |
| Piper на нашем сервере | Одинаковый нейросетевой голос, локальная обработка | Модели и CPU/RAM, контейнер, очередь, API и хранение аудио | Резерв для следующей версии |
| Внешний облачный TTS | Обычно стабильно высокое качество | Текст книги уходит третьей стороне, есть ключи, лимиты и стоимость | Не подходит продукту |

Piper остаётся технически допустимым локальным резервом: это быстрый локальный
TTS с моделями голосов, но его эксплуатационная цена для семейного приложения
сейчас не оправдана. Справка: [Piper](https://github.com/OHF-Voice/piper1-gpl).

## Реализация в ридере

Озвучивание доступно только после нажатия на слово — в уже открытой словарной
карточке. Автоматически читать текст при открытии карточки нельзя.

| Режим | Текст |
|---|---|
| «Слово» | Выбранная словоформа (`selection.word`) |
| «Контекст» | Короткое окно вокруг слова (`selection.translationText`) |
| «Предложение» | Предложение с выбранным словом (`selection.fullSentence`) |

Карточка содержит отдельные кнопки «Слово», «Контекст» и «Предложение». Во
время воспроизведения они заменяются на «Остановить»; повторное нажатие,
закрытие карточки, смена главы, уход со страницы и размонтирование ридера
вызывают
`speechSynthesis.cancel()`.

Для каждого запроса задаются `lang = 'en-US'`, громкость `1`, скорость по
умолчанию `0.9` и высота `1`. Голос выбирается так: сохранённый подходящий
голос, затем любой `en-US`, затем любой `en`. Если голоса нет, кнопка
недоступна с объяснением «В браузере нет английского голоса».

Текст нормализуется до одиночных пробелов, ограничивается 1 200 символами и
при необходимости разбивается по границам предложений. Части читаются
последовательно по `end`; `error` завершает очередь и восстанавливает кнопку
без записи текста книги в логи.

## Данные, доступность и границы

- Никакие данные для TTS не сохраняются в базе и не попадают в словарь.
- Запуск происходит только после явного действия пользователя.
- Название режима, состояние «воспроизводится» и остановка доступны с
  клавиатуры и через `aria-label`.
- Выбор голоса и скорости — персональная настройка ридера в
  `user_reader_settings`: `tts_voice_uri` и `tts_rate` (`0.6..1.2`).
- В v1.3 нет аудиофайлов, чтения всей книги, синхронизации аудио с текстом,
  загрузки голосов и внешних TTS API.
