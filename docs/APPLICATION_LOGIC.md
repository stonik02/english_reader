# Прикладная логика: EPUB, ридер, перевод и словарь

## Книга: только EPUB

PDF в системе не поддерживается. Формат рассчитан на фиксированное размещение,
поэтому плохо сочетается с изменением размера шрифта и стабильной позицией
чтения. На первом экране загрузки UI принимает только `.epub` и объясняет это
ограничение.

```text
Загрузка EPUB → проверка ZIP/MIME/лимитов → распаковка и sanitization
             → извлечение метаданных, обложки, глав и CFI → READY / FAILED
```

Файл и обложка сохраняются в закрытый файловый volume, а в PostgreSQL —
метаданные и подготовленные XHTML-главы. После загрузки книга появляется в
общем семейном каталоге, а не только у загрузившего её человека. Воркер внутри
`reader-api` помечает книгу `PROCESSING`, затем `READY` или `FAILED`; при
перезапуске подхватывает незавершённые записи. Нельзя исполнять HTML из EPUB:
scripts, inline events, внешние URL и опасный CSS удаляются до сохранения.
Полный протокол загрузки, структура хранения и выдача глав описаны в
[документе о файлах книг](BOOK_STORAGE_AND_DELIVERY.md).

У каталожной книги и личной библиотеки разные понятия. Пользователь явно
добавляет готовую книгу кнопкой «Добавить в мою библиотеку», либо система
добавляет её идемпотентно, когда он впервые начинает читать. Личная библиотека
содержит только такие связи; удаление из неё не удаляет общий EPUB и не влияет
на другие аккаунты.

## Ридер

Позиция определяется EPUB CFI, а не номером страницы: она не ломается, когда
член семьи меняет шрифт. В `reading_progress` одна запись на `(user_id, book_id)`
с CFI, процентом и `revision`. Клиент сохраняет её после перелистывания с
debounce и при уходе со страницы; сервер оставляет новую revision. Открытие
всегда начинается с последнего CFI либо с начала книги.

Размер шрифта (80–200%, шаг 5%), тема и межстрочный интервал — личные настройки.
Они применяются локально в EPUB renderer и не меняют CFI. Вперёд/назад ридер
переходит по chapter spine и отображаемой части главы.

## Словарная карточка и бесплатный перевод предложения

При выделении клиент отправляет выбранную форму, lemma (если уже известна),
предложение и CFI. Backend нормализует слово и отдаёт все подходящие значения:
часть речи, русские варианты, пример и атрибуцию. Словарная база — локальный
нормализованный импорт Wiktionary. До импорта нужно проверить атрибуцию и
лицензию CC BY-SA для производных данных.
[Wikimedia Terms of Use](https://foundation.wikimedia.org/wiki/Special:MyLanguage/Policy:Terms_of_Use)

Для перевода **предложения** выбираем LibreTranslate, запущенный отдельным
локальным контейнером c парами моделей `en`/`ru`. Он бесплатен при
self-hosting, не передаёт текст книги стороннему публичному API и не требует
подписки. Официальная документация подтверждает, что self-hosted instance не
нуждается в API key; публичный `libretranslate.com` для production требует
платный ключ, поэтому его не используем.
[LibreTranslate API usage](https://docs.libretranslate.com/guides/api_usage/)
[LibreTranslate FAQ](https://docs.libretranslate.com/guides/faq/)

Качество перевода проверяется на нескольких семейных книгах до релиза. Если
сервис недоступен, модалка всё равно показывает словарные данные, а перевод
предложения — кнопку повтора. В PostgreSQL сохраняется небольшой кэш
`(normalized_sentence, en, ru, model_version)` с TTL; повторный запрос не
тратит ресурсы модели.

## Личный словарь и подсветка

Нажатие `+` сохраняет `(user_id, lemma_id)`; повторное действие идемпотентно и
меняет кнопку на «в словаре». Страница словаря показывает только записи текущего
пользователя, постранично, с поиском и удалением.

При открытии главы клиент получает lemmas текущего пользователя. Тот же
токенизатор/нормализатор оборачивает совпавшие text nodes в `mark`, не собирая
пользовательский текст через `innerHTML`. На первом этапе при неизвестной lemma
подсвечивается точное нормализованное совпадение — это явно документированное
ограничение, а не попытка угадать форму слова.

## Вне первой версии

- PDF, OCR, EPUB с DRM, общий каталог, sharing книг и подписки.
- Офлайн-копии и сложное разрешение конфликтов между устройствами.
- Другие языки книги/перевода, кроме English → Russian.
