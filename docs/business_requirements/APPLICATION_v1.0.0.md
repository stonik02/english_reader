# Бизнес-требования 
## 1. Библиотека:
1. Должна быть поддержка аккаунтов под разных пользователей
2. Клиент может загружать книги форматов epub. Эти книги попадают в общую библиотеку книг
3. Клиент может добавлять книгу в свою библиотеку кнопкой, либо если начнет читать
4. Клиент может просматривать список своих книг

## 2. Ридер
1. Клиент может открывать отдельную книгу. В этом случае у него должен открываться текст книги на последней странице, где он остановился
2. Клиент может проматывать страницы вперед/назад
3. Клиент может менять размер шрифта

## 3. Встроенный переводчик
1. Клиент может зажать палец/курсор на слове, и тогда ему откроется модальное окно с подсказкой: переводом этого слова на русский язык. Если оно переводится по разному - указать все варианты перевода и части речи, которыми слово может быть
2. Так же в этой модалке должен быть пример использования этого слова.
3. Так же в модалке долен отображаться перевод предложения, в котором клиент переводит это слово.

## 4. Словарь
1. У клиента должен быть свой собственный словарь, в который он сможет сохранять слова из книг для запоминания.
2. В модалке из пункта 3 БТ должна быть иконка **+** для добавления слова в словарь.
3. Клиент может зайти на страницу со своим словарем, и просмотреть все слова, которые он туда добавил
4. Пока клиент читает книгу, ему нужно помечать все слова в тексте, которые находятся в его словаре

# Технические требования
- Разработка серверной части должна вестись в директории ./../backend
- Разработка клиентской части должна вестись в директории ./../frontend
- Должен использоваться GRPC для связи сервер-сервер, клиент-сервер

## Backend
- Использовать язык Go 1.25+
- Использовать AGENTS.md, который расположен в директории backend
- БД использовать postgres. Если найдется лучше для моих задач - уточнить у меня, и возможно использовать ее
