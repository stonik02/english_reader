# Бизнес-требования 
## 1. Библиотека:
1. Нужно как-то поправить отображение книг. Нужно, чтобы было видно картинку из книги

## 2. Ридер
1. Добавить клиенту возможность выбирать цвет выделения для слов из словаря

## 3. Встроенный переводчик
1. Клиент может зажать палец/курсор на слове, и тогда ему откроется модальное окно с подсказкой: переводом этого слова на русский язык. Если оно переводится по разному - указать все варианты перевода и части речи, которыми слово может быть
2. Так же в этой модалке должен быть пример использования этого слова.
3. Так же в модалке долен отображаться перевод предложения, в котором клиент переводит это слово.
