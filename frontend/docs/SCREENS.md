# Экраны frontend-приложения

Дата: 2026-09-03. Этот документ — понятная карта будущего интерфейса English
Reader. Приложение закрытое: доступно только после входа и предназначено для
семьи. Оно работает с английскими EPUB-книгами и переводит на русский.

## Как читать документ

- **Экран** — отдельная страница в браузере с собственным адресом.
- **Модальное окно** — небольшое окно поверх текущей страницы; адрес не меняется.
- **Состояние** — вариант того же экрана: например, загрузка, пустой список или
  ошибка.
- Слева в URL ниже указано, каким будет адрес страницы. Точные имена маршрутов
  можно будет немного скорректировать при реализации, но их назначение останется
  тем же.

## Общая оболочка приложения

После входа все основные страницы, кроме ридера, имеют одинаковую верхнюю
панель:

- название приложения / переход в «Мою библиотеку»;
- навигация: «Моя библиотека», «Общий каталог», «Словарь»;
- email текущего пользователя и кнопка «Выйти».

На мобильном экране пункты навигации превращаются в компактное меню. Во время
запроса данных показывается индикатор загрузки; при ошибке — понятный текст и
кнопка «Повторить».

## 1. Вход — `/login`

**Задача:** впустить уже зарегистрированного члена семьи в его личный аккаунт.

Содержимое:

- поля email и пароль;
- кнопка «Войти»;
- ссылка «Создать аккаунт»;
- сообщение об ошибке при неверных данных или недоступном сервере.

При успехе приложение сохраняет только краткоживущий access token в памяти
страницы; refresh token находится в защищённой cookie, недоступной JavaScript.
Пользователь перенаправляется в «Мою библиотеку» либо обратно на страницу,
которую он пытался открыть.

## 2. Регистрация — `/register`

**Задача:** создать новый семейный аккаунт.

Содержимое:

- поля email, пароль и подтверждение пароля;
- подсказки о требованиях к паролю;
- кнопка «Создать аккаунт»;
- ссылка «Уже есть аккаунт? Войти»;
- ошибки проверки формы и сообщение, если email уже занят.

После успешной регистрации пользователь сразу входит в систему и попадает в
«Мою библиотеку».

## 3. Моя библиотека — `/library`

**Задача:** показать книги, которые пользователь добавил для чтения.

Содержимое:

- заголовок «Моя библиотека»;
- кнопка «Открыть общий каталог»;
- карточки книг: обложка, название, автор, статус и сохранённый процент чтения;
- действие «Читать» для готовой книги;
- действие «Убрать из моей библиотеки». Оно не удаляет EPUB из семейного
  каталога и не влияет на других пользователей;
- постраничная подгрузка книг, если список длинный.

Состояния:

- **пусто:** объяснение, что книгу можно добавить из общего каталога;
- **обработка:** книга есть в списке, но вместо «Читать» показано
  «Подготавливаем EPUB»;
- **ошибка обработки:** текст ошибки и предложение обратиться к тому, кто
  загрузил книгу.

## 4. Общий каталог и загрузка — `/catalog`

**Задача:** дать семье общий список EPUB и добавить новую книгу.

Содержимое:

- заголовок «Общий каталог»;
- кнопка «Загрузить EPUB»;
- карточки всех загруженных книг с обложкой, названием, автором и статусом;
- кнопка «Добавить в мою библиотеку» у готовой книги; после успеха меняется на
  «В моей библиотеке»;
- ссылка/кнопка «Читать»: первое открытие также автоматически добавляет книгу в
  личную библиотеку;
- постраничная подгрузка.

### Модальное окно загрузки EPUB

Открывается кнопкой «Загрузить EPUB».

- выбор файла перетаскиванием или кнопкой;
- принимается только файл `.epub`, с подсказкой о максимальном размере;
- имя файла, размер и кнопки «Загрузить» / «Отмена»;
- прогресс отправки файла;
- результат: «Книга загружена и подготавливается». Карточка появляется в
  каталоге со статусом `PROCESSING`.

Файл отправляется через HTTP `multipart`-endpoint: это отдельное решение для
файла, потому что браузерный gRPC-Web не поддерживает нужную потоковую загрузку.
Остальные действия приложения используют gRPC-Web через Envoy.

## 5. Ридер — `/reader/:bookId`

**Задача:** комфортно читать EPUB, не теряя место и не выходя из контекста при
переводе слов.

Содержимое:

- верхняя панель: назад в библиотеку, название книги, текущий прогресс;
- область текста EPUB;
- кнопки/жесты «предыдущая страница» и «следующая страница»;
- панель настроек: размер шрифта 80–200% с шагом 5%, тема и межстрочный
  интервал;
- индикатор сохранения позиции: «Сохранено» или «Сохраняем…»;
- подсветка слов, уже добавленных в личный словарь.

Открытие начинается с последней сохранённой позиции (EPUB CFI), а не с номера
страницы: поэтому смена размера шрифта не сбивает место чтения. Позиция
сохраняется после перелистывания с небольшой задержкой и при выходе из ридера.
Если EPUB ещё обрабатывается, экран объясняет это и предлагает вернуться в
каталог. Если загрузка главы не удалась, остаются кнопки «Повторить» и
«Вернуться в библиотеку».

### Модальное окно перевода

Открывается при выделении слова мышью, долгим нажатием на телефоне или с
клавиатуры.

- выбранное слово и его нормальная форма;
- все найденные значения: часть речи и русские переводы;
- пример употребления;
- перевод предложения, где было выбрано слово;
- источник и атрибуция словарных данных;
- кнопка `+` «Добавить в словарь» либо состояние «В словаре»;
- закрытие по кнопке, Escape и нажатию вне окна; фокус не уходит за пределы
  окна.

Словарные значения и перевод предложения загружаются отдельно. Если временно
недоступен машинный перевод, значения слова всё равно отображаются, а для
предложения есть кнопка «Повторить».

## 6. Личный словарь — `/vocabulary`

**Задача:** показать слова, сохранённые только текущим пользователем.

Содержимое:

- заголовок «Мой словарь»;
- поле поиска по слову;
- постраничный список карточек: слово, часть речи, перевод и пример;
- действие «Удалить» с подтверждением;
- кнопка перехода обратно в библиотеку.

Состояние пустого списка объясняет, что слово можно добавить кнопкой `+` из
модального окна перевода. После удаления слово перестаёт подсвечиваться при
следующем открытии либо обновлении главы.

## 7. Страница «Не найдено» — `*`

**Задача:** безопасно обработать неправильный адрес.

Показывает сообщение «Страница не найдена» и кнопку «В мою библиотеку». Если
пользователь не вошёл, кнопка ведёт на экран входа.

## Защита маршрутов

Страницы `/library`, `/catalog`, `/reader/:bookId` и `/vocabulary` доступны
только после проверки сессии (`GetMe`). При истечении сессии клиент один раз
пытается обновить её, затем направляет пользователя на `/login`.

## Что сознательно не входит в первую версию

Нет PDF, публичных страниц, подписок, оплаты, общего доступа к отдельным книгам
и офлайн-чтения. Книги — только English EPUB, перевод — English → Russian.
