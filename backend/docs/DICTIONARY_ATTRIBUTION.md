# Атрибуция словарных данных

Встроенный словарь импортируется из versioned структурированного экспорта
Wiktionary, а не извлекается со страниц сайта во время пользовательского
запроса.

Для каждого sense сохраняются URL источника и строка attribution. Frontend
показывает attribution рядом со словарной карточкой. Данные Wiktionary должны
распространяться с сохранением требований **CC BY-SA**; перед импортом новой
версии необходимо проверить её лицензию и записать source/version/checksum в
`dictionary_import_runs`.
